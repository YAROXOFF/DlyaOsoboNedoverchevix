## Стек

- Vite и Vanilla JavaScript (ES modules)
- Семантический HTML и чистый CSS: переменные тем, Grid, Flexbox, адаптивные стили
- Docker multi-stage: Vite build и Nginx Alpine для раздачи production-файлов

## Архитектура

Контент сайта централизован в [`src/data/siteContent.json`](src/data/siteContent.json): участники, биографии, навыки, достижения, проекты, контакты, подписи интерфейса и пути изображений. `src/js/render.js` безопасно строит разметку из данных, а `src/js/interactions.js` отвечает за темы, карусель, фильтры, перевороты карточек и модальное окно. Стили разделены на базовые компоненты и адаптивные правила.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка и локальный просмотр:

```bash
npm run build
npm run preview
```

## Запуск в Docker

Из корня репозитория выполните:

```bash
docker compose up -d --build
```

Сайт будет доступен по адресу [http://localhost:8080](http://localhost:8080). Остановить контейнер можно командой `docker compose down`.

## Структура репозитория

```text
.
├── public/images/             # Логотип, фото команды и участников
├── src/
│   ├── data/siteContent.json  # Единый источник контента и путей к изображениям
│   ├── js/                    # Рендеринг и интерактивность
│   └── styles/                # Основные и адаптивные стили
├── Dockerfile
├── docker-compose.yml
├── nginx.conf
└── index.html
```

Чтобы изменить тексты и ссылки, отредактируйте соответствующие значения в `src/data/siteContent.json`. Чтобы заменить заглушки фотографиями, положите файлы в `public/images/` и обновите пути участника в JSON, например `/images/member-1.jpg`. SVG-заглушки можно оставить как fallback-изображения или заменить напрямую файлами `.jpg`/`.png`.

## Использование ИИ

ИИ использовался как инструмент разработки для подготовки структуры проекта, шаблонов интерфейса, адаптивных CSS-правил и проектной документации. Сведения о команде и учебных активностях, а также контактные ссылки включены в единый JSON-файл и могут быть проверены и отредактированы командой перед публикацией. ИИ не заменяет проверку содержимого, сборки и результата в целевых браузерах.
